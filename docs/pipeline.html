ASIC Design RAG Pipeline

Data flow and entry points for the RAG system

Entry Point 1 Build a new vectorstore from a design directory
CorpusExecutor uv run corpus /path/to/build-dir
collect_documents Walk build dir, match files via STAGE_RULES, extract text + metadata
write_corpus Serialize documents to JSONL
corpus.jsonl — 475 docs, 25 MB
feeds into
IngestExecutor uv run ingest --chunker fixed|structured
load_and_chunk Split corpus docs using fixed-size or structure-aware chunker
init_vectorstore Create ChromaDB collection (deletes existing if present)
embed_and_store Embed chunks via OpenAI, insert into ChromaDB in batches
vectorstore/ — ChromaDB, ~20k chunks
Entry Point 2 Query the existing vectorstore
QueryExecutor uv run query "your question" [--filter-variant] [--rerank]
vectorstore/ — must already exist
init_clients Connect to OpenAI, Anthropic, and ChromaDB
ask Full retrieve-and-answer pipeline for one question:
extract_variant Detect design variant name in question text
retrieve Embed question, query ChromaDB for top-k nearest chunks
rerank Re-score chunks with Claude, re-sort by relevance
format_context Format chunks into numbered context string with metadata
generate_answer Send question + context to Claude, return cited answer
Entry Point 3 Evaluate the pipeline against a benchmark
EvalExecutor uv run eval [-o results.json] [--filter-variant] [--rerank]
vectorstore/
benchmark.jsonl — 30 questions
init_clients OpenAI + Anthropic + creates a QueryExecutor instance
load_benchmark Read benchmark questions with expected answers and source docs
run_eval For each benchmark question:
qe.retrieve Retrieve chunks (delegates to QueryExecutor)
qe.rerank Re-rank chunks (delegates to QueryExecutor)
score_retrieval Compute recall vs expected source docs
qe.generate_answer Generate answer (delegates to QueryExecutor)
grade_answer Claude grades answer vs expected on correctness + completeness
save_results Write detailed results to JSON
eval_results.json
Blue methods delegate to QueryExecutor (reuses retrieval + generation logic)
